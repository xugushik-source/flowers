==================================================
7. MASK / CLIP REVEAL
==================================================

Главные надписи должны появляться не простым fade.

Использовать:
mask / clip-path / overflow reveal.

Например:

clip-path:
inset(100% 0 0 0)

→

inset(0 0 0 0)

с:
translateY(25px → 0)

Получается эффект, будто буквы раскрываются изнутри.

Использовать для:
- LA FLEUR;
- hero headings;
- названий коллекций;
- крупных storytelling headings.

Не использовать на каждом мелком элементе.

58. PERFORMANCE

Несмотря на большое количество фотографий, сайт должен оставаться быстрым.

Обязательно:

* loading=“lazy” для изображений ниже первого экрана;
* width/height или aspect-ratio для предотвращения layout shift;
* WebP/AVIF где это разумно;
* preload только действительно критичного hero image;
* не загружать все большие фотографии сразу;
* минимизировать тяжёлые JS-зависимости.

Не подключать animation framework только ради простых reveal-анимаций, если это можно качественно сделать CSS + vanilla JS.
