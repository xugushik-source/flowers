==================================================
7. MASK / CLIP REVEAL
==================================================

Главные надписи должны появляться не простым fade.

Использовать:
mask / clip-path / overflow reveal.

Например:

clip-path:
inset(100% 0 0 0)

→

inset(0 0 0 0)

с:
translateY(25px → 0)

Получается эффект, будто буквы раскрываются изнутри.

Использовать для:
- LA FLEUR;
- hero headings;
- названий коллекций;
- крупных storytelling headings.

Не использовать на каждом мелком элементе.
