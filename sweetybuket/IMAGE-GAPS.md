# IMAGE-GAPS — Sweety Buket

Чего не хватает в доступном материале (заменить, когда появятся съёмки):

1. **Широкий hero/brand-кадр в высоком разрешении (≥ 2400 px по ширине).** Все сильные фото вертикальные. Для desktop hero сделан split-layout (текст | фото), а широкая полоса использует единственный горизонтально читаемый кадр (`brand`, 1440 px).
2. **Крупные детали цветов (FLOWER DETAIL).** Макро лепестков/бутонов почти нет — editorial-блоки собраны из кадров с моделями.
3. **Клубника в шоколаде отдельно, крупным планом, с хорошим светом.** Есть 3–4 кадра, часть снята на улице на тёмном фоне.
4. **Особенный вечер.** Нет вечерних/интерьерных кадров; плитка использует красные розы на подставке.
5. **Фото с ценой.** В подписях цена есть только у 1 поста из 500 — цены на сайте «по запросу».
6. **Видео в 1080p.** Instagram отдаёт Reels в 640–720 px; для видео-hero нужен исходник.
